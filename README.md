# Java RPG Project

Java를 복습하면서 각 챕터에서 배운 내용을
하나의 RPG 프로젝트에 단계적으로 적용하는 프로젝트입니다.

## 🎯 목표

- Java 기본 문법 복습
- 객체지향 프로그래밍 이해
- 자료구조 및 예외처리 적용
- 파일 입출력 적용
- 멀티스레드 학습
- 최종적으로 Socket 기반 멀티플레이 구현
